# Data & Insights section — concept & research

Status: **Blue Economy Observatory (phase 1) is built.** "Fleet Watch" (live AIS map, phase 2) is
still not built — see "Scope note" below. This documents the research and direction agreed for
the section, plus what shipped, so a future session doesn't start from zero.

## What's built (phase 1 — Blue Economy Observatory)

- **`insights.html`** — full Observatory page: headline stat tiles + two hand-drawn canvas charts
  (top short-sea shipping nations; short-sea vs. other freight split) + a Fleet Watch "coming next"
  placeholder + Eurostat sourcing line.
- **Homepage teaser** — `#insights` section on `index.html` (between Numbers and the CTA), with 3
  stat tiles + one chart, linking to the full page. Nav entry "Insights" added (ocean-pill, mobile
  drawer, footer).
- **`js/observatory.js`** — three-layer data resilience: live Eurostat fetch (CORS is open,
  verified) → committed snapshot (`assets/data/observatory.json`) → inline hardcoded constants.
  Draws the charts on `<canvas>`, respects `prefers-reduced-motion`/`body.lite` (skips the draw-in
  animation, renders the final state immediately).
- **`assets/data/observatory.json`** — committed real snapshot, regenerated by
  **`scripts/fetch-eurostat.sh`** (tested end-to-end against the live API).
- **Datasets used** (verified against the live API, not guessed): `mar_go_qm` (quarterly goods,
  IN+OUT summed to match Eurostat's own published-headline convention) and `mar_sg_am_cw`
  (short-sea shipping, country level, incl. a built-in `PC_TOT` percent-of-total unit).
- **Not built**: "Fleet Watch" live AIS ship map — deferred to phase 2, needs an aisstream.io API
  key and a server-side proxy/cache (Supabase Edge Function is the natural home; see below).

## Why

Federico wants a new section, on-theme with the rest of the site, that's visually striking ("wow",
"spettacolo e informazioni") and shows real data via APIs — not decorative/fake numbers.

## Data sources (researched, real — verify current terms before building)

| Source | What it gives | Access |
|---|---|---|
| **Eurostat REST API** — `ec.europa.eu/eurostat/api/dissemination` | Official EU maritime transport volumes, short-sea shipping by country, blue-economy indicators (GDP/jobs) | Free, **no API key**, JSON-stat format, dataset refreshed twice daily. Docs: `ec.europa.eu/eurostat/web/user-guides/data-browser/api-data-access/api-introduction` |
| **EMSA — EU Maritime Profile** | Curated EU maritime safety/sector stats & infographics | Public data portal; no confirmed clean REST API found — better used as a citation/source for context than as a live feed |
| **aisstream.io** | Live global ship positions via WebSocket (real-time AIS) | Free tier, **requires signup + API key** (`aisstream.io`) — good for a live moving-ships visual, not official statistics |
| AISHub | Free AIS data sharing | Requires *you* to feed them AIS data from a physical receiver to get access — not practical for a website. Ruled out. |

## Direction: chosen = Hybrid ("Fleet Watch" + "Blue Economy Observatory")

Three directions were scoped; Federico picked the hybrid:

- **"Fleet Watch" (spectacle)** — a full-width live nautical chart (canvas, in the style of the
  existing hero/nautical-chart engine in `js/canvas.js`) with live ship blips from aisstream.io
  drifting across European waters. Lat/lon HUD-style readouts are a nice callback to the coordinate
  HUD that was removed from the hero earlier — reused here where it's thematically apt. Animated
  counters ("X vessels tracked now"). High wow factor; depends on a third-party live feed's
  uptime/rate limits.
- **"Blue Economy Observatory" (substance)** — Eurostat-driven charts: EU short-sea shipping volumes
  by country, port throughput trends, blue-economy jobs/GDP, as animated count-up stat tiles and
  line/bar charts. Large Cormorant Garamond numbers echoing the existing `.num-val` styling
  (`css/style.css`, Numbers section). Most credible/on-mission for a "Do-Tank."
- **Hybrid (chosen)**: the "Fleet Watch" live map as the section's visual hook, with the "Blue
  Economy Observatory" stat band directly beneath it as the substance layer. Answers Federico's own
  framing — spectacle *and* information in one section.

## Technical approach (proposed, not yet implemented)

- **No build step, no framework** — matches the whole site's architecture (`CLAUDE.md`): everything
  loaded as plain `<script>` globals.
- **Charts**: Chart.js via CDN `<script>` tag (same pattern already used for the Supabase client in
  `admin/index.html`), styled in the navy/gold palette.
- **Live map**: hand-rolled `<canvas>` drawing, reusing patterns from `js/canvas.js` (nautical-chart
  overlay) and the hero's frame-scrub engine (`initScrollFrames` in `js/main.js`) for inspiration —
  not the same code, but the same "engraved chart" visual language (see `design.md`).
- **New nav entry** needed (Mission / Units / Network / Publications / Join currently) — where this
  slots in still needs deciding.
- **aisstream.io** needs a free account + API key before any live-map code can actually run.
- **Eurostat** needs no key — safe to prototype against immediately once scoped.

## Scope note

This is a genuinely new page/section: new nav entry, a new third-party API key, new chart/map code,
new design work within the existing system. It's sized like its own project, not a quick add-on —
deliberately **deferred to a separate, dedicated session** rather than folded into homepage-polish
work.
